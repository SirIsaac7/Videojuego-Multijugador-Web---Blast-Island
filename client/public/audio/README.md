# Música por arena

Coloca aquí archivos `.mp3`, `.ogg` o `.wav` y registra sus rutas en `src/data/arenas.js`.

```js
music: ['/audio/laguna-01.mp3', '/audio/laguna-02.ogg']
```

La lista se reproduce en orden; al terminar una pista comienza la siguiente y, al terminar la última, vuelve a la primera. Los efectos de juego se generan en el navegador.
